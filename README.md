# 💫 About Me:
I’m MIMENE Yakoub, an Electronics and Instrumentation Engineer with a Master’s degree from USTHB, Algeria. I’m passionate about electronics, embedded systems, and industrial automation. Through my projects, I’m continuously improving my technical skills and exploring new technologies.<br><br>My technical interests include C, C++, Python, MATLAB, and Assembly programming, as well as Arduino, ESP32, and Siemens TIA Portal for PLC programming and industrial automation.
